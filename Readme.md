## Introduction

This is a personal portfolio website created to display my work and skills. It includes interactive elements, such as a carousel for project showcases and a responsive design optimized for various devices.

## Features

- **Interactive Project Carousel:** Displays a selection of my projects with links to their repositories.
- **Responsive Design:** Ensures optimal viewing experience on desktops, tablets, and mobile devices.
- **Skills Section:** Highlights my expertise in frontend and backend development.
- **About Me Section:** Provides a detailed overview of my background and skills.
- **Contact Information:** Includes multiple ways to get in touch with me and links to my social media profiles.
